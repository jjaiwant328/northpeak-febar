# FE Bar Submission — NorthPeak Stockout & Markdown Rescue

Requirement (1): the build — code, notebooks, app, dashboards, with execution
evidence readable as text. This directory maps each requirement element to its
artifact. All data is synthetic (`rtdemo.northpeak_v2`, generated by
`northpeak-addons/data_generation/generate_data.py`); no customer data.

## The build

| Element | Artifact |
|---|---|
| App (code) | This repo — React client (`client/`), Node server (`server/`), agent (`server/agent/`), deployed via Databricks Asset Bundle (`databricks.yml`, `app.yaml`) |
| App (live) | https://northpeak-febar-687974281268075.aws.databricksapps.com — status evidence: `evidence/app_status.json` (RUNNING) |
| Data pipeline | `northpeak-addons/` — Lakeflow SDP bundle: generator (`data_generation/generate_data.py`) + silver/gold SQL (`transformation/silver/`, `transformation/gold/`) |
| ML notebook | `northpeak-addons/transformation/recovery_train_score.py` — trains XGBoost, registers `rtdemo.northpeak_v2.recovery_recommender`, batch-scores all open shortfalls |
| Dashboards | In-app Analytics page (`client/src/dashboard/DashboardView.tsx`) over the UC metric view `rtdemo.northpeak_v2.mv_store_position`; Genie space answers match it (`evidence/genie_answers.txt`) |
